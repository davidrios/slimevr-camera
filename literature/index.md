# Literature index

One line per note. Only papers with a note file here may be cited elsewhere in the project.

| Note | Topic (§ of research agenda) | Read depth | One-line takeaway |
|---|---|---|---|
| [2018-vonmarcard-vip-3dpw](2018-vonmarcard-vip-3dpw.md) | A (also G) | full read | Only paper that models per-IMU yaw drift explicitly (one angle per sensor about vertical) and solves it offline from 1 camera; 13 IMUs → 26 mm / 12.1° MPJAE on TotalCapture, and most of the gain comes from the heading fix (IMU-only 55→28 mm). No code; 3DPW non-commercial. |
| [2020-zhang-imu-multiview-geometric](2020-zhang-imu-multiview-geometric.md) | A | full read | IMU limb directions used as a prior to help 4-camera 2D/3D keypoints (24.6 mm TotalCapture); information flows camera←IMU, no drift model, no angle error. MIT code. |
| [2020-kaichi-imu-single-rgb](2020-kaichi-imu-single-rgb.md) | A | skimmed | 13 IMUs + 1 RGB, online; camera fixes root position only — orientation error unchanged (8.83° vs 8.75° IMU-only). No code. |
| [2023-pan-robustcap](2023-pan-robustcap.md) | A | full read | Real-time 6 IMU + monocular; root-relative IMU branch + camera branch, camera "re-calibrates" RNN state and translation, not an explicit yaw. 48.7 mm TotalCapture; no angle metric in-paper (13.4° SIP per later work, ≈ IMU-only). MIT code, MediaPipe. |
| [2025-pan-diffcap](2025-pan-diffcap.md) | A | full read | RobustCap successor with diffusion fusion; whole-window visual embedding + per-frame IMU; 46.2 mm TotalCapture, robust to 2D noise; still no heading estimate, magnetic drift left open. MIT code. |
| [2026-tang-stereo-inertial-poser](2026-tang-stereo-inertial-poser.md) | A (also D) | full read | 6 IMU + calibrated stereo (MediaPipe + disparity); big win is metric translation (TE 23→5–9 cm), hip/shoulder rotation only ~1–3° better (≈10–11°); IMU-only PNP matches it on TotalCapture. Code skeletal, no licence. |
| [2025-lee-spatiotemporal-people-calib.md](2025-lee-spatiotemporal-people-calib.md) | D(a),(d) | full read | Extrinsics + integer frame offset + person association from monocular 3D pose; 0.2–4.5° rotation on real 4-cam data, 0–1 frame sync; translation up to scale; no code; CPU-fast. |
| [2025-lee-steerpose.md](2025-lee-steerpose.md) | D(a) | skimmed | Learned 2D-only relative rotation + matching from articulated subjects; ~2.4° multi-view; code claimed released, licence unverified. |
| [2024-tang-cascalib.md](2024-tang-cascalib.md) | D(a),(b),(d) | skimmed | Open-source cascade: focal + ground plane from upright people, then 1-D sync, rotation search, BA; ~1.8° rotation, weak translation; no licence file. |
| [2018-takahashi-human-pose-calib-pattern.md](2018-takahashi-human-pose-calib-pattern.md) | D(a),(d) | skimmed | Joints as wide-baseline correspondences; joint sync (6–12 ms synthetic) + extrinsics + pose with relaxed reprojection and bone-length prior; no code, no degree numbers. |
| [2021-fei-single-view-distance-pose.md](2021-fei-single-view-distance-pose.md) | D(b) | skimmed | Single-view focal + ground plane from ankle/shoulder keypoints; floor normal 0.5–2° at 0.5–2 px noise, focal 3–12 %; no code. |
| [2026-yang-sports-stick-calib.md](2026-yang-sports-stick-calib.md) | D(a) | skimmed | Human keypoints + known-length stick: 0.02° / 0.1 cm synthetic vs 0.2–0.3° / 3–7 cm for people-only; MIT repo; 3+ cams, synchronised. |
| [2025-desousa-colocated-vr-hmd-alignment.md](2025-desousa-colocated-vr-hmd-alignment.md) | D(c) | skimmed | HMD tracked externally; fixed transform between HMD SLAM frame and mocap frame via Umeyama + pose least squares; 3–5 cm ATE; the math for HMD-as-fiducial. |
| [tool-liv-unreal-mrc-calibration.md](tool-liv-unreal-mrc-calibration.md) | D(c) | skimmed (docs) | LIV / Unreal MRC solve camera pose in SteamVR space from 3–16 tracked-controller-on-crosshair clicks (PnP); no published accuracy; HMD itself not used as fiducial anywhere. |
| [2023-goel-hmr2](2023-goel-hmr2.md) | B | skimmed | HMR2.0/4DHumans: ViT-H per-frame SMPL regressor in camera frame, fixed-focal camera; backbone of WHAM/TRAM/GVHMR/TokenHMR; 3DPW 70.0/44.5 mm; no rotation metric reported. MIT. |
| [2021-li-hybrik](2021-li-hybrik.md) | B | skimmed | HybrIK/-X: swing from 3D joints analytically, twist as learned 1-DoF per joint; twist ablation (est. 10.0 vs zero 12.1 vs random 67.3 mm PVE); only neck/elbow/wrist have wide twist range; EMDB MPJAE 24.5°. MIT, ResNet-34/HRNet. |
| [2023-shin-wham](2023-shin-wham.md) | B | skimmed | WHAM: temporal world-frame SMPL from 2D keypoints + camera angular velocity; 3DPW PA-MPJPE 35.9; world heading integrated autoregressively → drifts on long clips (GVHMR Fig. 9); no MPJAE. MIT, CUDA, static-camera mode. |
| [2024-wang-tram](2024-wang-tram.md) | B | skimmed | TRAM: masked DROID-SLAM + metric depth for camera, VIMO (frozen HMR2.0 ViT-H + temporal transformer) for camera-frame SMPL; EMDB WA-MPJPE 76.4 vs WHAM 133.3; needs focal; no rotation metric. MIT. |
| [2024-shen-gvhmr](2024-shen-gvhmr.md) | B | skimmed | GVHMR: per-frame gravity-aligned "Gravity-View" frame, non-autoregressive → bounded global orientation error (Fig. 9); SMPL-X out; RICH WA-MPJPE 78.8; fast; static-camera flag. **Non-commercial ZJU licence.** |
| [2025-wang-prompthmr](2025-wang-prompthmr.md) | B | skimmed | PromptHMR: DINOv2 ViT-L full-image promptable SMPL-X, optional intrinsics ray encoding, temporal + SLAM world mode; best 2025 numbers (EMDB PA-MPJPE 40.1, WA-MPJPE 71.0); no angular metric; licence unverified, no training code. |
| [2024-dwivedi-tokenhmr](2024-dwivedi-tokenhmr.md) | B | skimmed | TokenHMR: shows wrong fixed-focal camera + 2D loss corrupts 3D pose; tokenized pose prior; EMDB MPJPE 91.7 vs HMR2.0 99.3; no MPJAE. Non-commercial MPI licence. |
| [2023-cai-smplerx](2023-cai-smplerx.md) | B (also F) | abstract | SMPLer-X: SMPL-X foundation model, ViT-S…H 32M–662M params, 17–36 fps V100; per-frame; no rotation metric; old mmcv stack. Smallest variant is a CPU-quantization candidate. |
| [2023-kaufmann-emdb](2023-kaufmann-emdb.md) | B (also G) | skimmed | EMDB: EM-sensor GT (10.6° own angular accuracy); the benchmark that reports MPJAE — 2023 per-frame SMPL regressors sit at **22–25° per-joint** (HybrIK 24.5°, CLIFF 23.1°); none of the 2024–25 world models publish MPJAE. |
| [2025-ludwig-uplift-rotations](2025-ludwig-uplift-rotations.md) | B | skimmed | 2D-keypoint → SMPL-X rotation lifter with rotation supervision: MPJAE 9.2° vs Multi-HMR 17.6° on fit3D (studio); evidence that ~10° is reachable in-domain and that generic HMR is ~2× worse. |
| [2018-huang-dip](2018-huang-dip.md) | C (also G) | full read (calibration/eval sections) | Founding 6-IMU poser: heading reference from one aligned sensor + straight-pose bone offsets (= SlimeVR full/mounting reset); sensors physically heading-aligned before session; drift never modelled or measured; ~16–17° joint angle error on TotalCapture/DIP-IMU. DIP-IMU 17 Xsens, 92 min, no video. |
| [2021-yi-transpose](2021-yi-transpose.md) | C | full read (appendix A, §5) | T-pose calibration + one axis-aligned sensor for world frame; root-relative normalisation hides global yaw from the network; §5.5.1 admits heading comes from the magnetometer and fails in varying fields; SIP err 14.95° / ang 12.26° TotalCapture. GPL-3.0. |
| [2022-yi-pip](2022-yi-pip.md) | C | skimmed + drift section | Physics optimiser on TransPose; only paper in the line to ask about pose drift: 4.2° over 4.6 h with *synthetic ideal* input (network drift, not sensor drift); translation drift 4.6 % of distance; SIP 12.93° TotalCapture. GPL-3.0, CPU-capable. |
| [2022-jiang-tip](2022-jiang-tip.md) | C | skimmed + appendix D | Transformer poser; "drift" = root position via stationary body points, heading untouched; T-pose before every use; longest robustness check is 50 s windows. CC BY-NC-SA. |
| [2024-yi-pnp](2024-yi-pnp.md) | C | full read (§3.2.3, Table 1) | Synthesises low-level gyro/acc/mag + own fusion, perturbs T-pose calibration (0.6°/5.7°) in training; quantifies TotalCapture calibration error as 12.1° (official) vs 8.6° (DIP re-cal) and shows models absorb ~1° of it; no time-varying yaw handling. GPL-3.0. |
| [2025-zuo-tic](2025-zuo-tic.md) | C (also E) | full read | Online Transformer estimates time-varying world-drift R_G'G and mounting R_BS per sensor in an *ego-yaw* frame; without it every 6-IMU method's angular error ~doubles over long sessions (PNP 15.5°→30.6°, Table 3); explicitly "does not support correction of global yaw drift" and fails in low-activity (seated) use — the gap a camera fills. |
| [2025-yi-globalpose](2025-yi-globalpose.md) | C | fetched summary of HTML | Walking-step calibration (R_BS + relative heading in one step, no T-pose), gravity refinement for tilt, 3D translation; 20-min Nymeria test shows no pose-error growth — but with mag-aided Xsens; SIP 10.87° TotalCapture. Numbers unverified against PDF. CC BY-NC-SA. |
| [datasets-imu-video](datasets-imu-video.md) | G | web pages + source papers | TotalCapture (13 Xsens + 8 static cams + Vicon, calibration 8.6–12.1° off) is the only usable test bed for "camera fixes IMU yaw"; 3DPW raw-IMU release unverified and GT is IMU-derived; DIP-IMU/CIP have no video; Nymeria 20-min sequences but egocentric. No public set has mag-off consumer IMUs. |
