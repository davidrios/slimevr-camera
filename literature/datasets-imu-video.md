# Datasets with body IMUs + video + ground-truth pose (§G)

- **Read depth:** dataset web pages + originating papers (3DPW ECCV'18 §5.3, TotalCapture BMVC'17 §3/§4, DIP SIGGRAPH Asia'18 §4.5, Nymeria project/HF pages, CIP Sci. Data'22 via PMC). Nothing downloaded; "raw IMU provided?" is from documentation only unless stated.
- **Date read:** 2026-08-26

What we need from a test bed: (a) per-sensor IMU **orientation as the sensor reported it** (with heading error still in), (b) RGB video from a static or known camera, (c) pose ground truth independent of the IMUs. Nothing public has all three with consumer-grade, mag-off IMUs.

## Which is the best test bed for "camera corrects IMU yaw"

1. **TotalCapture** is the only set with (a) per-sensor IMU orientations whose calibration is known to be imperfect (8.6–12.1° per PNP), (b) *static, calibrated* RGB cameras — our deployment geometry, (c) optical GT independent of the IMUs. Sequences are a few minutes each, so magnetometer-aided Xsens heading barely drifts; to test *drift* we would add synthetic gyro-only yaw drift on top of the real orientations (per-sensor random walk / scale-factor × rotation), which is what PNP's synthesis pipeline does for noise. Downside: registration/approval, 5 subjects, studio scenes.
2. **3DPW** matches the "one consumer camera, in the wild" story but the camera moves, GT is derived from the same IMUs, and raw IMU availability is unverified. Use as a secondary qualitative set, not for heading accuracy.
3. **DIP-IMU** and **CIP** have no video — useful only to characterise IMU behaviour (CIP's MPU-9250 raw gyro is the closest public analogue to BMI270-class drift).
4. **Nymeria** is the only 20-min+ set (GlobalPose uses it for its long-term test) but egocentric/moving cameras and unclear raw-IMU release make it a poor fit.

Conclusion: no public dataset reproduces our regime (mag-off consumer IMU, minutes-to-hours, static webcam). Plan on **TotalCapture + injected drift** for method development and our own recordings with SlimeVR trackers + optical/HMD reference for the real thing.
